# Amazon Sales Dashboard – Power BI

## Project Overview

This project presents an interactive Power BI dashboard for analyzing
Amazon sales data.

The project demonstrates the use of Power BI to transform data, develop
visualizations, and present sales-related insights through an interactive
dashboard.

## Objectives

- Analyze Amazon sales data
- Identify sales patterns and trends
- Present sales information through interactive visualizations
- Develop a business intelligence dashboard using Power BI

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Project Workflow

1. Data Import
2. Data Cleaning and Transformation
3. Data Modeling
4. Data Analysis
5. DAX Calculations
6. Visualization Development
7. Interactive Dashboard Creation

## Key Features

- Interactive sales dashboard
- Sales data visualization
- Filtering and data exploration
- Business-focused dashboard presentation
- Visual representation of sales insights

1. Download or clone the repository.
2. Open `SalesAmazon_dashboard.pbix` using Microsoft Power BI Desktop.
3. Use the dashboard filters and visualizations to explore the sales data.

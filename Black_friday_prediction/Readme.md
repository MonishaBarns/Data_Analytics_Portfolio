# Black Friday Purchase Prediction

## Project Overview

This project focuses on predicting customer purchase amounts during
Black Friday using machine learning techniques.

The analysis uses customer demographic information and product-related
features to build and compare different regression models.

## Dataset

The project uses two datasets:

- `train.csv` – Training dataset used to build the machine learning models.
- `test.csv` – Test dataset used to generate predictions.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow

1. Data Loading
2. Data Understanding
3. Exploratory Data Analysis
4. Data Preprocessing
5. Categorical Feature Encoding
6. Feature Preparation
7. Model Training
8. Model Evaluation
9. Model Comparison
10. Final Prediction

## Machine Learning Models

The following regression models were explored:

- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

The models were evaluated using:

- R² Score
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)

## Results

The performance of the different regression models was compared using
the evaluation metrics above. The final model was selected based on
the model comparison performed in the notebook.

## How to Run

1. Clone this repository.
2. Open `Black Friday.ipynb` using Jupyter Notebook or VS Code.
3. Make sure `train.csv` and `test.csv` are in the same project folder.
4. Run the notebook cells sequentially.

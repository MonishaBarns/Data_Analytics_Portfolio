# E-Commerce Sales Analysis – Power BI

## Project Overview

This project presents an interactive Power BI dashboard for analyzing
e-commerce sales performance, profitability, customer segments, products,
markets, and shipping information.

The dashboard was created using Power BI with an e-commerce dataset
containing order, return, and regional information.

## Dataset

The source Excel workbook contains three sheets:

- `Orders` – Order and sales transaction data
- `Returns` – Returned order information
- `People` – Regional information

The Orders dataset contains 51,290 records and includes information such as:

- Order Date
- Ship Date
- Ship Mode
- Customer
- Segment
- City
- State
- Country
- Market
- Region
- Category
- Sub-Category
- Product
- Sales
- Quantity
- Discount
- Profit
- Shipping Cost
- Order Priority

## Dashboard Analysis

The dashboard provides insights into:

- Sales performance
- Profitability
- Quantity sold
- Shipping costs
- Sales by Category
- Sales by Market
- Sales by Ship Mode
- Sales by Country
- Sales by State
- Customer and product performance

## Key Dashboard Metrics

The dashboard includes KPI cards for:

- Total Sales
- Total Profit
- Total Quantity
- Total Shipping Cost

# Netflix Dashboard – Power BI

## Project Overview

This project presents an interactive Power BI dashboard created to
analyze and visualize Netflix-related data.

The dashboard demonstrates the use of Power BI for transforming data,
creating visualizations, and presenting insights through an interactive
business intelligence report.

## Objectives

- Explore Netflix data through interactive visualizations
- Identify patterns and trends in the dataset
- Present information using an easy-to-understand dashboard
- Practice data visualization and dashboard development using Power BI

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Project Workflow

1. Data Import
2. Data Cleaning and Transformation
3. Data Modeling
4. Data Analysis
5. Visualization Development
6. Interactive Dashboard Creation

## Key Features

- Interactive Power BI dashboard
- Data filtering and exploration
- Visual analysis of Netflix-related data
- Dashboard-based presentation of insights

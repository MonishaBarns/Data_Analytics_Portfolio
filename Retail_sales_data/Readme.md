# Retail Sales Data Analysis

## Project Overview

This project analyzes retail transaction data to identify sales trends,
customer purchasing behavior, and key business insights.

The analysis was performed using Python, with a focus on data exploration,
sales trend analysis, and customer-level analysis.

## Dataset

The dataset contains 124,969 retail transaction records with information
including:

- Customer ID
- Transaction Amount
- Response
- Transaction Date
- Month

## Tools & Technologies

- Python
- Pandas
- NumPy
- SciPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

### Data Understanding & Cleaning

- Inspected data types and dataset structure
- Checked for missing values
- Checked for outliers using Z-score
- Converted the transaction date into a datetime format

### Sales Analysis

- Calculated total sales
- Analyzed daily sales
- Analyzed monthly sales
- Examined sales patterns across different time periods

### Customer Analysis

- Analyzed transaction-level customer behavior
- Identified customer purchasing patterns
- Performed customer segmentation using RFM analysis

## Key Findings

- The dataset contains 124,969 transaction records.
- Total transaction sales in the analyzed dataset were 8,122,378.
- Monthly and daily sales patterns were analyzed to understand
  variations in transaction activity.
- Customer purchasing behavior was explored using transaction-level
  analysis and RFM segmentation.

## How to Run

1. Clone the repository.
2. Open `myproject_RetailSalesData.ipynb` in Jupyter Notebook or VS Code.
3. Make sure `formatted_data.csv` is in the same folder as the notebook.
4. Run the notebook cells sequentially.

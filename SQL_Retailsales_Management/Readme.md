# Sales Retail Management System – SQL

## Project Overview

This project focuses on designing and implementing a Smart Retail
Management System (SRMS) using SQL Server.

The database is designed to manage products, categories, suppliers,
customers, orders, employees, warehouses, payments, sales, and inventory.

## Project Goals

- Manage product and category information
- Manage suppliers and warehouse stock
- Manage customer orders and payments
- Track employees involved in order processing
- Support sales and inventory reporting
